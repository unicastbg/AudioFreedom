# Historical personal-use ViPER DSP notice

AudioFreedom private test versions `0.8.x` contained a Dynamic System experiment derived
from the publicly available ViPERDSP reverse-engineering project:

- https://github.com/likelikeslike/ViPERDSP
- Original ViPER4Android work by Zhuhang and ViPER520
- Reverse-engineering credits: Martmists, Iscle, and likelikeslike

ViPERDSP states that the original intellectual property remains with its authors and
permits personal use only, with no commercial use. Those historical binaries and source
revisions must remain private, personal-use, and non-commercial.

Version `0.9.0-foundation1` removes that implementation and its coefficient presets. Its
Bass Foundation replacement uses an independently selected low-band enhancement design.
This removal does not retroactively permit distribution of a historical `0.8.x` build.
