# Route1 test

## Install

1. Install `AudioFreedom-xuanyuan-eea-0.7.0-route1-directbind.zip` in Magisk or
   KernelSU and reboot.
2. Install `AudioFreedom-0.7.0-route1-debug.apk` over the current app.
3. Allow notification permission when requested.
4. Confirm the app reports `Driver attached` and processing can be enabled.

## Stronger effects

1. Use a familiar stereo song and keep Output protection enabled.
2. Compare Detail recovery off against Clear, then Crisp.
3. Compare Immersive field off against Wide music, then Cinema.
4. Check that Amount at 0 percent remains an exact bypass for each effect.
5. Listen for harshness, exaggerated sibilance, center-image movement, or clipping.

## Output and profiles

1. Confirm the icon beside AudioFreedom matches the active phone, wired, Bluetooth,
   USB, or HDMI output.
2. Save at least two named profiles, such as `Headphones` and `Phone speaker`.
3. Open Settings, enable Automatic profiles, and assign the current output a profile.
4. Connect another output, assign its profile, and switch between the two outputs.
5. Confirm the route icon, notification device name, profile name, and all controls
   update for each output.

## Settings

1. Disable Show connected device and confirm the required processing notification
   remains but omits the output name.
2. Test System, Light, and Dark appearance modes.
3. Place or receive a call and confirm processing pauses, then resumes afterward.

The foreground processing notification itself is mandatory on modern Android while
AudioFreedom keeps the system-wide effect alive.
