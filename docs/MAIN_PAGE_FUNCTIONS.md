# Main Page Functions

Settings > Appearance > Main page functions controls which sections appear on the main page.
All nine sections are visible by default, including on upgrades.

- Hiding an effect turns it off immediately and saves that disabled state.
- Showing it again restores its controls, not its enabled state.
- Slider values remain saved. The EQ preamp is bypassed while the EQ is disabled.
- Profiles, automatic route profiles, A/B snapshots, and assistant changes cannot enable hidden effects.
- Saved profiles and A/B snapshots themselves are not modified by visibility choices.
- Hiding Playback analysis stops its analysis requests. Hiding A/B comparison keeps the snapshots.
- Processing, driver status, profiles, and Settings remain accessible.
- The local assistant retains its existing separate enable setting.

Visibility is saved locally using stable function keys. Unknown future keys are ignored.
This is a companion-app change; the driver module does not need updating.
