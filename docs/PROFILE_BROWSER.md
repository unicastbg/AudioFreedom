# Profile Browser

The main screen shows the current output's profiles first, followed by **Any device**
profiles. Tap a chip to switch. With **Remember profile per device** enabled,
AudioFreedom recalls the last profile you picked or saved for an output when it
reconnects. An existing opt-out in Settings is preserved.

Tap the active profile name or down arrow to open the searchable picker. The connected
output is first, other outputs start collapsed, and **Any device** is last. Each
profile shows its EQ curve and active effects. The profile menu offers **Rename**,
**Move to**, **Duplicate**, and **Delete**.

## Save and Rename

- For a modified profile, **Save** offers **Update**, **Save as new**, and **Revert changes**.
- New profiles are saved for the current output unless you choose **Any device**.
- To rename an output group, tap the pencil beside its heading. The new name appears
  in the profile controls and does not change the output ID or its remembered profile.
  **Use device name** resets the label. **Any device** cannot be renamed.

Switching away from modified settings asks before discarding them. Deleting a saved
profile removes its remembered assignments without changing the current sound.

## Existing Profiles

On first launch, an assigned profile moves under its assigned output. An old group
that matches the connected output moves under that output. Other profiles go under
**Any device**, with their old group name kept as a tag. Nothing is deleted; use
**Move to** to organize them.

For voice selection, use a unique profile name. Custom output-group names are
display labels, not new voice aliases.
