# Bass2 listening test

## Install

1. Install `AudioFreedom-xuanyuan-eea-0.7.2-bass2fix-directbind.zip` in Magisk or
   KernelSU and reboot.
2. Install `AudioFreedom-0.7.1-bass2-debug.apk` over the current app.
3. Confirm `Driver attached`, then enable Processing.

## Isolated comparison

1. Keep the same phone, Bluetooth codec, HiFi input, song, and HiFi tone controls.
2. Disable EQ, Detail recovery, and Immersive field for the first comparison.
3. Keep Output protection enabled with a -1.0 dB ceiling.
4. Toggle Dynamic bass off and on using the Deep extension preset.
5. Bass2 reserves broadband headroom. Raise the HiFi volume about 3 to 4 dB with
   bass enabled before comparing depth at matched perceived loudness.
6. Try Sub-bass system next. It is intentionally narrower and strongest below about
   50 Hz.

## What to listen for

- Bass should extend lower without adding a thick 150 to 300 Hz character.
- Kick impact and bass notes should remain individually recognizable.
- Vocals should stay centered and should not pulse with the bass.
- Occasional limiter movement is expected. Constant heavy gain reduction means the
  Strength should be reduced.
- Phone speakers should use a separate profile with Dynamic bass off or Natural;
  Deep extension and Sub-bass system are intended for capable headphones and HiFi.

The most useful report includes the preset, Bluetooth codec if known, HiFi model,
whether the comparison was volume-matched, and the typical limiter reduction.
