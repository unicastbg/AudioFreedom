# AudioFreedom 0.9.6 Beta

This release adds playback-level control, analysis and comparison tools, and a simpler
main page for users who do not need every effect.

## Changes since 0.9.5

- **Volume Leveler** reduces the difference between quiet and loud passages. Gentle
  preserves more dynamics, Balanced provides moderate leveling, and Night brings quiet
  and loud passages closer together. Each preset now has a short explanation. This does
  not change the phone's hardware volume or calibrate loudness at your ears.
- **Playback analysis** shows input/output RMS, output crest factor, stereo correlation,
  near-full-scale sample counts, and a ten-band output spectrum. Analysis runs only while
  its section is open on the visible main page. It does not record, retain, or upload audio.
- **A/B comparison** saves two independent DSP snapshots per output route. Store A,
  adjust the sound, Store B, and switch between them while listening. Both Store buttons
  are accessible, and identical snapshots still highlight the selected slot correctly.
- **Main page functions** in Settings > Appearance lets you hide unused effects and tools.
  Everything is shown by default. Hidden effects are disabled, their values stay saved,
  and profiles or assistant commands cannot re-enable them. Showing an effect again leaves
  it off until you enable it.
- **Voice widget fix:** the microphone can start another command after the previous one
  completes, without closing and reopening the panel.
- Volume Leveler settings are included in profiles, A/B snapshots, and assistant undo.
  Its standard assistant commands are listed in the in-app guide.

## Installation and upgrading

1. Install **AudioFreedom-universal-0.9.6-beta.zip** using your root-module manager,
   or use the app's driver installer.
2. Reboot to activate the updated native driver.
3. Install **AudioFreedom-0.9.6-beta.apk** over the existing app to retain settings,
   profiles, and downloaded assistant packs.
4. Open AudioFreedom, confirm the driver is detected, and enable processing.

Unlike the 0.9.5 app-only milestone, this release includes a newer DSP driver. Update the
module for Volume Leveler and playback analysis. With an older driver, leave Volume Leveler
off; playback analysis will indicate that a driver update is needed.

## Notes

Volume Leveler is optional and off by default. Begin at moderate device volume. It can
amplify noise in an active recording; it is not a denoiser. Linked sample-peak protection
remains active while leveling, even if the separate Output protection setting is off.

A/B comparison is manual, not blind ABX testing or automatic level matching. Analysis
readings are digital signal measurements, not acoustical measurements or a guarantee
that speakers and headphones will be distortion-free.

This remains a beta for rooted Android 15+ devices. Compatibility depends on the ROM,
effect factory, SELinux policy, and playback route. Hardware-offloaded audio may bypass
software effects. Existing reference-device compatibility is unchanged.

Validation: 138 app unit tests, Android lint, release build, native DSP tests, and emulator
checks for A/B saving and main-page visibility. Additional device testing is welcome.
