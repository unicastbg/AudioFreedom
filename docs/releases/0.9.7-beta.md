# AudioFreedom 0.9.7 Beta

This app-focused release adds visual themes, direct APK updates, and an optional one-way
music command bridge. The DSP driver is unchanged from 0.9.6-beta.

## Rebuilt APK (Build 39)

The 0.9.7-beta APK was rebuilt on October 12, 2026 with dedicated Mocha effect tiles,
Daylight grouped cards, Studio rack rows, and an interactive curve/fader equalizer.
The modern layouts include a processing card, profile chips, and a live spectrum when
processing is available; Classic retains the original layout. Mocha's two-column tile
sizing also accounts for fractional screen densities. No driver update is needed.

Build 39 passed all 158 app tests, lint without errors, and emulator smoke checks for
Mocha, Daylight, Studio, and the equalizer sheet. These UI checks used an unrooted
emulator, not an on-device audio-processing test.

The filename and visible version are unchanged, with internal versionCode increased to
39. If you already installed 0.9.7, re-download the APK from this release and install it
over the existing app. Same-version rebuilds are not offered by the version-name-based
in-app update check. Existing pending downloads may need cancellation and a fresh check
because the replacement APK has a new verification hash.

## Changes Since 0.9.6

- **Themes in Settings > Appearance:** Classic remains available alongside Mocha,
  Daylight, and Studio. Classic, Mocha, and Daylight support System, Light, and Dark modes;
  Studio is always dark. Theme changes apply immediately, including the voice panel.
- **Direct app updates:** Check updates checks both the app and driver. Download a newer
  APK in Settings, let AudioFreedom verify its hash, package identity, signing certificate,
  version, and bundled driver, then confirm installation in Android. Downloads survive
  closing Settings, and a separate View on GitHub link remains available.
- **Optional Media Player commands:** explicit requests such as Play trance, Play The
  Prodigy, Next track, Pause music, and Stop music go directly to a compatible player.
  Artist and track names bypass the DSP planner and Qwen. The connection is intentionally
  one-way: Media Player cannot start AudioFreedom's microphone.
- **Bridge reliability:** listening focus is released before forwarding; optional spoken
  replies use brief ducking focus in the main app, widget, and volume-button path. Request
  IDs, execution deadlines, cancellation, and safe controller cleanup prevent duplicate
  or stale requests from being treated as fresh commands. Unavailable, incompatible,
  unsupported, and unconfirmed requests have distinct messages.
- **Music help:** say Music help, or consult the expanded in-app command guide. Cancel
  and bare Stop still cancel listening; Stop music controls playback. Music requests
  execute immediately, without a DSP confirmation question or DSP undo snapshot.

## Installation and Upgrading

**AudioFreedom-0.9.7-beta.apk includes the universal driver module.** You do not need a
separate ZIP download for installation through the app.

1. Install the APK over the existing app to retain settings, profiles, and assistant packs.
2. For a first installation, open **Settings > Updates > Driver module > Install**, confirm,
   grant root access, and wait for successful installation.
3. Reboot after installing the driver, reopen AudioFreedom, and enable processing.

**Already using the 0.9.6-beta driver? No module reinstall or reboot is needed for this
app update.** The included driver and optional manual download remain version 0.9.6-beta;
the app is version 0.9.7-beta. This is intentional because no native DSP changes are needed.

For manual driver installation, use **AudioFreedom-universal-0.9.6-beta.zip** with Magisk,
KernelSU, or a compatible root-module manager, then reboot. Installing the APK alone does
not automatically install or activate the root module.

An older app may open GitHub when checking for this update. Download and install 0.9.7
there once; subsequent updates can use the new in-app Download and Install workflow.

## Compatibility and Limits

Rooted Android 15+ requirements and device compatibility are unchanged. Playback routes,
effect factories, SELinux policy, and hardware offload still affect DSP processing.

The music bridge requires a Media Player build that supports the versioned bridge and
shares AudioFreedom's signing certificate. Older or differently signed builds are not
silently accepted. The player must have its music library indexed for artist/genre lookup.
AudioFreedom does not include or install Media Player, and this release does not publish
a new Media Player APK. Other music players and mixed music/DSP sentences are not supported.

English speech recognition and an installed offline English Android TTS voice are required
for voice input/readback. If a response is lost, check playback before repeating a request.
The assistant is not continuously listening, and no audio or library data is sent to a cloud.

## Validation

158 app unit tests passed, Android lint completed without errors, and the signed release
build completed successfully. All three existing native regression suites also passed.
The bridge also passed 11 distinct emulator scenarios across absent-player and
installed-player runs, including Android audio-focus return, deadline and duplicate
rejection, cancellation/reconnection, and signing compatibility. MediaPlayer's seven
receiver unit tests passed. Real-device artist recognition and audible music/readback
remain part of user testing; the theme illustrations are not visual test evidence.
