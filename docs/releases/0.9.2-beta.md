# AudioFreedom 0.9.2 Beta

AudioFreedom 0.9.2 Beta improves the persistent processing notification while keeping the
system-wide DSP and universal audio module unchanged.

## Changes

- Added output-specific notification icons for phone speaker, wired audio, Bluetooth,
  USB, and HDMI.
- Added route-specific notification accents where the Android system UI supports them.
- Stopped profile and DSP changes from redundantly reposting the notification.
- Kept meaningful notification updates for route changes and call pause/resume states.

## Install

Existing AudioFreedom users can install the new APK over build 16 without reinstalling
the root module or rebooting.

New users should:

1. Install `AudioFreedom-universal-0.9.0.zip` using Magisk, KernelSU, or a compatible
   root-module manager.
2. Reboot.
3. Install `AudioFreedom-0.9.2-beta.apk`.
4. Open AudioFreedom, confirm that the driver is detected, and enable processing.

## Compatibility

Validated reference devices remain the Xiaomi 15 Ultra on Android 16 / HyperOS and the
Sony Xperia 1 III on LineageOS 23. Compatibility depends on the device's Android Effects
Factory, effect configuration, linker rules, SELinux policy, and playback route.
Hardware-offloaded streams may bypass system-wide software effects.

This beta APK retains the development signature used by earlier public builds so existing
testers can update in place. A permanent production signing key is still required before
the eventual 1.0 release.
