# AudioFreedom 0.9.3 Beta

AudioFreedom 0.9.3 Beta adds an on-demand update checker to the companion app.

## Changes

- Added an Updates section to Settings.
- Show the installed app version and clear checking, up-to-date, available, and retry
  states.
- Check AudioFreedom's latest public GitHub release only when requested by the user.
- Open available updates on their verified GitHub release page.
- Compare semantic versions correctly across beta and stable releases.
- Added no background polling, automatic downloads, or silent installation.

## Install

Existing AudioFreedom users can install `AudioFreedom-0.9.3-beta.apk` over the previous
beta without reinstalling the root module or rebooting.

New users should:

1. Install `AudioFreedom-universal-0.9.0.zip` using Magisk, KernelSU, or a compatible
   root-module manager.
2. Reboot.
3. Install `AudioFreedom-0.9.3-beta.apk`.
4. Open AudioFreedom, confirm that the driver is detected, and enable processing.

## Compatibility

Validated audio-processing reference devices remain the Xiaomi 15 Ultra on Android 16 /
HyperOS and the Sony Xperia 1 III on LineageOS 23. The update-check UI has passed unit,
lint, debug, and minified release builds; a physical-device UI check is still pending.

This beta APK retains the development signature used by earlier public builds so existing
testers can update in place. A permanent production signing key is still required before
the eventual 1.0 release.
