# AudioFreedom 0.9.4 Beta

Compared with 0.9.3 Beta, AudioFreedom 0.9.4 Beta introduces the local assistant,
offline voice control, a home-screen voice widget, and a dedicated system-wide reverb effect.

## Changes

- Added a collapsible Reverb section with Amount, Space, Damping, and Decay controls.
- Added Studio, Room, Hall, and Arena reverb presets.
- Saved profiles now include all reverb settings.
- Added a typed local assistant with safe previews, bounded tonal adjustments, profile
  selection, and one-step undo.
- Added a dedicated Local assistant settings page.
- Added the pinned on-device llama.cpp runtime and constrained Qwen command protocol.
- Grounded the local model in AudioFreedom's controls and live DSP state, while routing saved
  profile names through the deterministic command layer.
- Cached the shared AudioFreedom manual prefix while the model remains loaded, avoiding
  repeated processing of unchanged instructions.
- Added deterministic saved-profile selection and explicit on/off commands for Equalizer,
  Bass foundation, Detail recovery, Immersive field, Reverb, and Output protection.
- Added verified in-app Install, Update, and Remove actions for the optional Qwen language
  model and Whisper voice language pack, with progress and Wi-Fi-only controls.
- Added offline Whisper push-to-talk with selectable language, transcript review or immediate
  submission, a 20-second recording limit, and automatic stop during calls.
- Improved short Bulgarian commands by removing the English bias in automatic detection and
  retrying unsupported automatic transcripts with explicit Bulgarian decoding.
- Added a standard assistant command grammar for increasing, reducing, and toggling bass,
  mids, treble, vocals, detail, width, reverb/echo, effects, and saved profiles.
- Added a collapsible in-app command guide and a publishable reference with English and
  Bulgarian examples.
- Added optional playback pausing and offline spoken read-back of the validated DSP action before
  an automatically submitted voice command is applied.
- Made spoken interpretation independent from automatic application and added an offline voice
  test with explicit unavailable/error status in Assistant settings.
- Assistant tonal commands now preserve the user's preamp instead of changing overall level for
  automatic EQ headroom.
- Added a resizable AudioFreedom voice widget with direct in-app installation, a compact
  level-reactive voice panel, automatic end-of-speech detection, interpretation review,
  app-independent command application, and a one-cell minimum size.
- Added persistent one-step assistant Undo shared by the main app, widget button, and the voice
  command "Undo the last change."
- Added optional private thumbs-up/down personalization after applied commands. Recent outcomes
  guide future local model decisions, never leave the phone, and can be disabled at any time.
- Kept manual GGUF import as an advanced option and app-private model storage.
- Made Keep ready the default model-memory policy, with optional one-minute and
  five-minute idle unloading.
- Changed the distributed APK to a minified, non-debuggable release build while retaining
  the existing development certificate for update compatibility.

Wake-phrase listening is shown as a future mode but remains disabled until a dedicated
low-power keyword detector is integrated. AudioFreedom does not run full Whisper continuously.
The safe built-in command engine remains available without either model pack.

## Install

The Reverb DSP adds a new driver parameter, so both files must be updated for this beta:

1. Install `AudioFreedom-universal-0.9.4-beta.zip` in Magisk, KernelSU, or a compatible
   root-module manager.
2. Reboot.
3. Install `AudioFreedom-0.9.4-beta.apk` over the existing app.
