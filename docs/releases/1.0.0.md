## Highlights

- Fixed interrupted DSP processing on LineageOS 24 with automatic recovery during playback.
- Find saved profiles by name or device, and choose a default for each output.
- See the live DSP format and get clearer guidance when driver updates need a reboot or GitHub is unreachable.

## Installation

Install the APK, then open **Settings > Updates > Driver module**. The APK includes
the driver. Install or update it if prompted, then reboot. The standalone ZIP is
also available for manual installation. App and driver versions are tracked separately.
