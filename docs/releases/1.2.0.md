## Highlights

- Quickly switch profiles for the connected output and recall the last used profile when it reconnects.
- Rename output groups to names like Home HiFi or Sony Amp without changing their assignments.
- Use one Save menu to update, save as new, or revert; browse profiles with EQ previews and active-effect badges.

## Installation

Install the APK over your existing app. Existing profiles are kept and sorted into
output groups or **Any device** on first launch. The bundled driver is unchanged at
1.1.0; no driver reinstall or reboot is needed if it is already active.
