# AudioFreedom 0.9.5 Beta

This milestone improves offline voice control, introduces optional experimental sound
tuning, and makes driver maintenance available from the app.

## Changes since 0.9.4

- One **Check updates** button in Settings checks both the app and driver against GitHub.
  The app update checker already existed in 0.9.4; the combined check is new.
- Install, update, or reinstall the universal driver from Settings with root-manager
  confirmation and package verification. The APK includes the current driver for offline
  installation. Driver installation still requires root and a reboot.
- Optional volume-button activation: hold the selected volume button to start a short
  voice session. There is no wake phrase or continuous microphone listening.
- Spoken command readback and yes/no confirmation, configurable speech wait and end-pause
  timing, call suspension, and a fresh volume-button press to interrupt the session.
- Say **Cancel**, **Help**, **What can you do?**, or topic requests such as **Equalizer help**.
  The in-app command guide includes examples and supported limits.
- Combined commands such as **Increase bass and treble** or
  **Increase bass and turn on reverb** apply together rather than losing one part.
- Assistant commands and spoken replies are now English-only, based on device testing.
  Existing language selections migrate to English. Other languages are not advertised as
  supported.
- Offline speech-voice selection, preview, and clear warnings when a TTS engine or an
  installed offline English voice is missing.
- Optional conversational sound tuning under **Experimental features**, with examples,
  bounded proposals, preserved controls, manual approval, and undo. The local model is
  optional; standard commands do not require it. It does not analyze the music or perform
  automatic acoustic calibration.

## Downloads and upgrading

Install **AudioFreedom-0.9.5-beta.apk** over the existing app to retain settings and profiles.

The native driver is unchanged from 0.9.4. The release includes
**AudioFreedom-universal-0.9.4-beta.zip** for new installations and repair. Existing users
with a working 0.9.4 driver do **not** need to reinstall it for this app update.

Whisper and the optional conversational model remain separate downloads. Existing packs
remain usable. Voice recording and model inference run locally; checking for updates or
downloading packs requires an internet connection.

## Beta limitations

Speech recognition depends on microphone quality and background noise. Voice readback
requires a separately installed offline English Android TTS voice. Volume-button
activation requires the optional AudioFreedom accessibility service and microphone
permission; it does not inspect screen content.

This remains a beta for rooted Android 15+ devices. ROM-specific effect integration and
hardware-offloaded playback can affect DSP availability. Experimental model proposals
are not guaranteed to improve every recording or headphone.
