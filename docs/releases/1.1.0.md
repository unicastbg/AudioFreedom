## Highlights

- Per-band EQ bandwidth and stereo routing, with optional temporary system spatial-audio control.
- A profile manager with multi-select group moves, rename, duplicate and clearer saving.
- DSP edits survive screen rotation; routing now explains when a playback path is bypassed.

## Installation

Install the APK over the existing app. In **Settings > Updates > Driver module**,
install the bundled 1.1.0 driver if offered, then reboot. If that driver is already
installed and active, no additional module installation is needed.

System spatial-audio control is optional and requires confirmation and root access.
It affects other apps while active and restores the previous setting when routing
or processing stops, or the output changes. Unsupported playback paths remain bypassed.

Tap the app name in **Settings > Updates** to reopen these release highlights.
