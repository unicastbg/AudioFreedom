# Dynamic System 1 listening test

1. Install the matching `0.8.0-dynamicsystem1` APK and direct-bind module, then reboot.
2. Keep Output protection enabled with a `-1.0 dB` ceiling for the first test.
3. Disable EQ and the other effects so only Dynamic System changes the signal.
4. Select `High-end headphones (original)` and start at `20%` strength.
5. Compare Processing on/off, then raise strength in 5% steps. Try `35%` and `50%`.
6. Listen for deeper sub-bass below the kick drum, less 100-180 Hz muddiness, stable
   vocals, and no crackling or pumping.
7. Compare the original profile with `High-end headphones (v2)`. The v2 profile is
   milder and narrower.

The original profile can generate very large low-frequency peaks. Reduce strength or
enable more negative preamp if the limiter meter remains active continuously.
