# Profiles1 test

This is an APK-only update. Keep the AudioFreedom 0.6.0-immersive1 Magisk or
KernelSU module installed. No module reinstall or reboot is required.

1. Install `AudioFreedom-0.6.1-profiles1-debug.apk` over the current app.
2. Configure several effects, then tap the plus icon in the Profile row.
3. Name the profile and save it.
4. Change several settings and confirm the Profile row says `Current settings`.
5. Open the profile menu and select the saved profile.
6. Confirm EQ, Dynamic bass, Detail recovery, Immersive field, and Output
   protection all return to their saved values and affect playback immediately.
7. Change a value, tap the save icon, and confirm the selected profile updates.
8. Tap the delete icon and confirm the selected profile is removed.

Profiles are stored locally in the AudioFreedom app data. Uninstalling the app or
clearing its storage removes them.
